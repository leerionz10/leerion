# iPhone Simulator (웹 시뮬레이터)

아이폰/안드로이드 브라우저에서 사용할 수 있는 iOS 스타일 인터랙티브 웹 시뮬레이터의 시작 프로젝트입니다.

## 포함 기능

- 반응형 잠금 화면과 홈 화면
- iOS 스타일 앱 아이콘, Dynamic Island 모양, 위젯과 독
- 메시지 앱: 연락처별 대화, 메시지 입력, 키워드 기반 자동 답장
- 사진 갤러리: 이모지 플레이스홀더 또는 이미지 URL
- 전화 키패드 데모
- 음악 화면 데모
- 연락처, 메모, 설정, Safari 데모 화면
- 관리자 페이지: 배경, 위젯 문구, 사진 항목, 연락처, 자동 답장 규칙, 음악/메모 편집
- 관리자 설정 JSON 내보내기
- GitHub Pages에 배포할 수 있는 정적 파일 구조

## 로컬 실행

`index.html`을 브라우저에서 열어도 대부분 동작합니다. 권장 방법은 VS Code의 Live Server 같은 정적 웹 서버를 사용하는 것입니다.

## GitHub에 올리기

1. GitHub에서 새 저장소를 만듭니다. 예: `ios-simulator`
2. 이 폴더의 파일을 저장소 루트에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Deploy from a branch**를 선택하고 `main` 브랜치 및 `/(root)` 폴더를 지정합니다.
5. 저장 후 Pages가 제공하는 주소로 접속합니다.

공개 저장소에 올릴 경우 프로젝트 코드와 기본 콘텐츠는 공개됩니다. 비밀 키, 비밀번호, 개인 정보는 코드에 넣지 마세요.

## 중요한 현재 한계

### 관리자 설정 저장
이 버전은 `localStorage`를 사용합니다. 즉, 관리자가 설정을 수정한 브라우저에 저장되며 방문자 기기로 자동 동기화되지 않습니다. 관리자 페이지의 `/admin.html` 경로는 숨겨진 보안 경계가 아닙니다. 실제 운영 전에는 인증과 서버 측 권한 검사가 필요합니다.

### 모든 방문자에게 같은 콘텐츠 표시하기
다음 단계에서 인증된 관리자 로그인, 공용 설정 데이터베이스, 이미지 스토리지를 연결해야 합니다. GitHub Pages는 정적 호스팅이므로 자체 데이터베이스나 서버 API를 실행하지 않습니다. 별도 백엔드 또는 호환되는 관리형 서비스를 연결할 수 있습니다.

### 방문자별 대화
현재 메시지 기록은 설정 객체에 저장되어 같은 브라우저의 로컬 설정을 사용합니다. 운영 버전에서는 방문자별 대화를 분리하고, 데이터 보존/초기화 정책을 정해야 합니다.

### 전화와 음악
전화는 화면 시뮬레이션이며 실제 전화망/SMS와 연결되지 않습니다. 음악 화면은 UI 데모입니다. 실제 오디오 재생은 사용 권한이 있는 음원 파일을 추가해야 합니다.

### 사진
이미지 URL 입력은 기본 지원합니다. 실제 업로드와 안정적인 저장은 스토리지 연결 후 구현해야 합니다.

## 폴더 구조

```text
ios-simulator/
├── index.html      # 방문자용 시뮬레이터
├── styles.css      # 시뮬레이터 UI
├── app.js          # 앱 화면/메시지 자동 응답
├── admin.html      # 관리자 페이지
├── admin.css       # 관리자 UI
├── admin.js        # 콘텐츠 편집/내보내기
└── README.md
```
